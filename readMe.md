# StringArtConverter

**CURRENTLY STILL IN DEVELOPMENT**

Turn any image into **string art**: load a photo, preprocess and generate a sequence of nail-to-nail lines. Includes live preview, export, and a responsive UI (Qt/PySide6).

---

## ✨ Features

- **Desktop UI** 
- **Preprocessing pipeline**  
- **Greedy Solver**
- **Renderer**  
- **Export**
